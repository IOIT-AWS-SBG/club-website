# AWS Student Builder Group Website

This repository contains the source code for the official website of the AWS Student Builder Group (AWS SBG) at AISSMS Institute of Information Technology (AISSMS IOIT).

## About AWS Student Builder Group

AWS Student Builder Group is a student community focused on learning, exploring, and building with cloud technologies and Amazon Web Services (AWS).

The club provides students with opportunities to develop practical technical skills, work on projects, participate in technical activities, and collaborate with fellow students interested in cloud computing and emerging technologies.

## Objectives

- Promote learning and awareness of AWS and cloud technologies.
- Provide opportunities for hands-on technical learning.
- Encourage students to work on practical and real-world projects.
- Organize technical workshops, sessions, and learning activities.
- Encourage collaboration, innovation, and knowledge sharing.
- Help students develop skills relevant to cloud computing and modern technologies.

## Activities

The AWS Student Builder Group conducts and participates in activities such as:

- AWS and cloud computing workshops
- Hands-on technical sessions
- Project development activities
- Coding and technical events
- Open-source contributions
- Technical discussions and knowledge-sharing sessions

## Website

This repository contains the source code for the AWS Student Builder Group website at AISSMS IOIT.

The website provides information about the club, its activities, projects, members, and relevant updates.

## Contributing

Contributions to this project are welcome.(before contributing, kindly contact the AWS student builder lead at AISSMS IOIT.

To contribute:

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Commit your changes with a clear commit message.
5. Push your branch to your fork.
6. Open a Pull Request.

Please ensure that your contributions are relevant to our project and bring value to our club. 

## Community

AWS Student Builder Group encourages students to learn, build, collaborate, and contribute to the technical community.
